Deckd is a native DJ application developed by Gaming Evolution Centre using C++ and JUCE.

## About Deckd

Deckd is designed around a dual-deck DJ workflow with a native desktop interface.

## Features

- Dual DJ decks
- Jog wheels
- Waveform displays
- Mixer
- Crossfader
- EQ controls
- Gain controls
- Volume controls
- Level meters
- Track information
- Music library support
- Recording controls

## Development

Deckd is currently under active development.
